# 📈 投资学堂

一个开源的投资知识学习平台，基于经典投资书籍与权威资料，帮助普通人建立正确的投资观念。

## ✨ 项目特点

- **📚 内容权威** — 所有知识来自公认的投资经典书籍和官方资料
- **💬 对话式学习** — 像聊天一样学习投资知识，降低学习门槛
- **🎯 三大品类** — 系统覆盖基金、股票、债券投资知识
- **🤖 AI 对接** — 支持接入大模型 API，也支持对接 GPTs、LangChain 等
- **💻 零成本部署** — 纯静态页面，可部署在 GitHub Pages 等免费平台
- **📱 响应式设计** — 完美适配电脑、平板、手机各种设备

## 🚀 快速开始

### 本地运行

方式一：直接打开
- 双击 `index.html` 即可在浏览器中打开

方式二：本地服务器（推荐）
```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js
npx serve .

# 或使用 PHP
php -S localhost:8000
```

然后访问 `http://localhost:8000`
